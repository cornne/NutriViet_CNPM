# Spec Kit Artifacts (PA2 - 2026)

This directory contains the initialization artifacts for **GitHub Spec Kit** for the **NutriViet** project, in compliance with Part C of Project Assignment 2 (PA2-2026).

| **Checklist Template** | [checklist-template.md](./checklist-template.md) | Quality validation and readiness checklist (`/speckit-checklist`). |
